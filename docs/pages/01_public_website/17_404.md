# 404 PAGE SPECIFICATION
**HomeLink 2.0 Enterprise Documentation**

## 1. Title & Purpose
**Page Name:** 404
**Module:** 01 PUBLIC WEBSITE
**Purpose:** Menampilkan halaman "Tidak Ditemukan" yang ramah ketika pengguna mengakses rute yang tidak ada (mis. tautan properti yang sudah dihapus atau salah ketik URL), dengan jalur kembali yang jelas ke Beranda atau pencarian properti.

## 2. Next.js Routing Path
```text
app/(01_public_website)/404/page.tsx
```
*(Catatan: pada Next.js App Router, halaman ini secara teknis diimplementasikan sebagai `app/not-found.tsx` global atau `not-found.tsx` bersarang; path di atas merepresentasikan lokasi spesifikasi dokumentasi, bukan nama file konvensi Next.js.)*

## 3. Required UI Components (Shadcn/ui)
- `Button` (variant `default`, CTA "Kembali ke Beranda"; variant `outline`, "Cari Properti")
- (Tidak memerlukan `Card`/`Input`/`Skeleton` — halaman statis tanpa data dinamis)

## 4. Data & State Management
- **Konten:** Sepenuhnya statis; tidak ada fetch data atau state kompleks.
- **Local State:** Tidak ada.
- **Server State:** Tidak ada.
- **Form Handling:** Tidak ada form pada halaman ini.

## 5. API Endpoints Referenced
- Tidak ada endpoint backend digunakan — halaman ini murni tampilan statis error routing di sisi client/server Next.js.

## 6. Acceptance Criteria (DoD)
- [ ] Halaman merespons dengan status HTTP 404 yang benar (bukan 200 dengan konten "not found").
- [ ] Tombol "Kembali ke Beranda" dan "Cari Properti" berfungsi dan mengarah ke rute yang benar.
- [ ] Tidak ada header/footer navigasi kompleks yang membingungkan — fokus pada pesan dan dua CTA utama.
- [ ] Pesan menjelaskan situasi dengan jelas (mis. "Halaman yang Anda cari tidak ditemukan atau sudah dipindahkan") tanpa menyalahkan pengguna.
- [ ] Kontras warna dan tata letak lolos audit Lighthouse Aksesibilitas > 90.
- [ ] Mobile: ilustrasi/CTA tetap terpusat dan tidak terpotong pada layar kecil.

## 7. Iconography Specification
**Library:** Lucide React ONLY.

#### Icon: `SearchX`
- **Purpose & Business Meaning:** Ikon utama ilustrasi halaman 404, menandakan "tidak ditemukan".
- **Size:** `48px` (ilustrasi hero, lebih besar dari standar UI karena berperan sebagai fokus visual utama halaman error). **Stroke Width:** `1.5`. **Color:** `text-muted-foreground`.

#### Icon: `Home`
- **Purpose & Business Meaning:** Ikon di dalam tombol "Kembali ke Beranda".
- **Size:** `20px`. **Stroke Width:** `1.5`. **Color:** mengikuti warna teks tombol (putih di atas `blue-700`).

#### Icon: `Compass`
- **Purpose & Business Meaning:** Ikon opsional di dalam tombol "Cari Properti" sebagai ajakan eksplorasi ulang.
- **Size:** `20px`. **Stroke Width:** `1.5`.

## 8. UI/UX Aesthetic Rules (Mockup Reference)

Halaman ini **DIWAJIBKAN** untuk dibangun dengan mematuhi pedoman visual dari `Mockup.png`: background putih dominan, aksi utama `Royal Blue` (`blue-700`), teks `Dark Navy` (`slate-900`), border radius besar (`16-24px`) pada tombol.

**Spesifik halaman ini:** Layout terpusat penuh (centered) secara vertikal dan horizontal di viewport, **tanpa** header/navbar sticky dan footer kompleks yang biasa muncul di halaman publik lain — meminimalkan distraksi agar pengguna fokus pada dua jalur pemulihan (Beranda/Cari Properti).
